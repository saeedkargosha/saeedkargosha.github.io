# saeedkargosha.github.io

Personal website of Saeed Kargosha, built with [Astro](https://astro.build) and deployed to GitHub Pages.

```sh
npm install
npm run dev      # local dev server
npm run build    # build to ./dist
```

Posts live in `src/content/blog/` as Markdown. Pushing to `main` deploys the site (see `.github/workflows/deploy.yml`).
