When I tell people about my second brain, they imagine a big plan. A diagram. Maybe a weekend of setup.

The truth is the opposite. It started with one sentence in a chat:

> "When I say *add this to my todo*, put it in Notion. And send me my todo status on Telegram every morning."

That was it. No system, no diagram. Just one small thing that hurt.

## Week one: the todo list

My agent answered with a plan, and the first problem showed up at once. Notion had no todo page, and the agent could not even see my workspace. I had to share a page with it first.

So the first version was small and a bit ugly: one Notion database, one rule, and one message at 08:00 every day that says what is due and what is overdue.

It worked. I used it the next morning. That was enough.

## Then I kept hitting the next small pain

Every new piece came from a real annoyance, not from a plan:

- **I hate typing on my phone**, so I added voice notes. They are transcribed on the old MacBook itself.
- **Groceries** were scattered across notes, so they got a list and a skill.
- **Money** was in my head, so I tracked income and spending in Notion, and later imported my PayPal history.
- **Trips and flights** took hours of tabs, so the agent now compares options for me.
- **German words** would not stick, so the agent helps me make Anki cards.
- **Things to buy later** got a wishlist.
- **AI news** was too much to follow, so I get a short digest on Telegram every morning.
- **Learning links** got a home in Obsidian.
- **This website** came last. The agent drafts, and I decide what goes live.

Each one is a small skill: a short instruction file for one job.

## It is still messy

I want to be honest about this, because "perfect second brain" posts make it look easy.

- The agent sometimes writes to the wrong place. Then I fix the **skill**, not the single mistake.
- Speech-to-text turned "Saeed" into "Said".
- Some skills are long and some are tiny. Some I rewrote three or four times.
- I once found a stray divider on a page the agent made. I just removed it.
- Not everything works. Some automations still fail, and I fix them when I notice.

None of this stopped me. A messy system that I use beats a perfect one that I never finish.

## What I do now

When something annoys me twice, I ask: can the agent do this?

1. Start with the smallest version.
2. Use it for a few days.
3. Write down what went wrong.
4. Improve the skill, or add a connector.

After three weeks I have more skills and connectors than I planned. I never sat down to design them. They grew, one by one.

## If you want to start

Do not build a second brain. Build a **todo list** that talks to you every morning. When it works, add the next small thing.

The rest will follow.
